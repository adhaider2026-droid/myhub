انسخ الإعداد المناسب لعميلك — يعمل مع ChatGPT وClaude وCursor وغيرها

MCP ENDPOINT

في ChatGPT: Settings ← Connectors ← Create ← Custom MCP server وضع الرابط في «Server URL».

connector-config.json
{
  "mcpServers": {
    "media-generator": {
      "url": "https://<نطاق-النشر>/mcp"
    }
  }
}

الأدوات الخمس المتاحة عبر MCP:

generate_imageتوليد صورة من وصف نصي عبر gpt-image-2-6/flare-text-to-image
generate_videoتوليد فيديو بصوت متزامن عبر grok-imagine-video-1-5-preview
merge_videosدمج حتى 10 مقاطع في فيديو واحد بالترتيب المطلوب
get_taskتتبع أي مهمة بمعرّفها حتى الاكتمال
list_mediaاسترجاع أحدث الوسائط المخزنة بروابطها
الفيديو يحتاج دقائق: يعيد السيرفر task_id فورًا، ويتابع تلقائيًا بـ get_task كل 10 ثوانٍ — وعند اكتمال المهمة يُعرض الرابط في الدردشة ويتوقف. أثناء الانتظار يُبث تقدم حي (Progress notifications) حتى لا تنقطع العملية.
